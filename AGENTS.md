# Clasp Development Instructions

Read context.md before making architectural decisions.

This is a one-day hackathon project.

Priorities:
1. Working end-to-end demo.
2. Real hardware integration.
3. Deterministic authorization at tool execution.
4. Clear auditability.
5. Demo polish.

Do not invent hardware APIs.
Inspect Vexo Open Kit before writing integrations.

Do not simulate biometric verification without
explicitly labeling it as simulated.

Implement the smallest working solution first.
